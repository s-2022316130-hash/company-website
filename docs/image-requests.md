# Official image requests

The website shows a manufacturer's logo or model photo only after the distributor supplies the file, or confirms in writing that Nirob Autos may use it. Until then it shows the brand name in type and an original line drawing of the bike's body style. Being an authorized dealer is not, on its own, permission to republish the manufacturer's images.

This list is generated from the model directory: every current Bangladesh model has an image slot (see `src/config/images.ts` and `src/lib/images.ts`).

## Adding a file

1. Save a logo as `public/images/brands/<brand>.svg` (or `.webp`), and a model photo as `public/images/motorcycles/<model-id>.webp`, e.g. `bajaj-pulsar-n160.webp`.
2. In `src/config/images.ts`, add or update the entry with `src`, `width`, `height` and `rightsStatus: "dealer-supplied"` (or `"approved"`, noting who gave permission). The comments there show an example.
3. Run `npm run check`. The tests fail if a file is missing, is not local, or is marked `permission-required`.
