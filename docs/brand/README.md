## What the website uses

- `public/images/nirob/logo.png` and `logo-dark.png`: the emblem with the Bangla name, cut from the signboard image with the white made transparent. The `-dark` file turns the black ink white for dark backgrounds.
- `public/images/nirob/mark.png` and `mark-dark.png`: the emblem without the name band, for the header and other small spaces.
- `src/app/icon.png` and `apple-icon.png`: the mark on a white tile, for browser tabs and home-screen icons.
- `src/app/opengraph-image.png`: the image shown when a link to the site is shared on WhatsApp, Facebook and similar apps.

The manufacturer logos on the signboard and card are not used on the website: being a dealer does not give permission to republish them (see `docs/image-requests.md`).
